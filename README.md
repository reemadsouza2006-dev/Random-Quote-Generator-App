# 🌟 Random Quote Generator App

An Android application built using **Java and Android Studio** that displays random motivational quotes to inspire positivity, confidence, and productivity.

## 📌 About the Project

The Random Quote Generator App provides users with motivational quotes at the touch of a button. It is a simple Android project designed to practice Java programming and Android app development.

## ✨ Features

- 💬 Displays motivational quotes.
- 🔄 Generates a different quote when the user taps the button.
- 📱 Simple and user-friendly interface.
- ⚡ Lightweight Android application.
- 🎯 Encourages positivity and motivation.

## 🚀 Getting Started

### Prerequisites

- Android Studio
- Java Development Kit (JDK)
- Android SDK

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/reemadsouza2006-dev/Random-Quote-Generator-App.git
   ```

2. Open Android Studio.
3. Select **Open** and choose the cloned project folder.
4. Allow Gradle to sync.
5. Run the application on an Android emulator or compatible Android device.
